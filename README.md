# prueba-portafolio-gitver

Portafolio web de prueba hecho con HTML / JavaScript — versión “git ver.”  

## Descripción

Este repositorio contiene una versión inicial de un portafolio personal.  
Actualmente está en desarrollo, y su estructura básica incluye una página de inicio, una sección “About” y scripts en JavaScript.  

El objetivo es que este proyecto sirva como base para construir un portafolio web funcional donde puedas mostrar tus proyectos, habilidades e intereses.
